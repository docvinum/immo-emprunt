# Politique de sécurité

## Versions supportées

Seule la dernière version de la branche `main` reçoit des corrections de sécurité.

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique pour une faille de sécurité.

Utilise plutôt le signalement privé de GitHub : onglet **Security** → **Report a vulnerability** de ce dépôt (advisory privé).

Indique dans ton signalement :
- la description de la faille et son impact potentiel ;
- les étapes pour la reproduire ;
- la version ou le commit concerné, si possible.

Un accusé de réception est visé sous 7 jours, puis une évaluation et un correctif dès que possible. Une fois corrigée, la faille pourra être publiée dans un advisory crédité (sauf si tu préfères rester anonyme).
